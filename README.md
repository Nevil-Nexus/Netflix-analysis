# 🎬 Netflix Data Analysis with Python

## 📌 Project Overview

This project focuses on exploring and analyzing the Netflix dataset using Python.

The objective is to discover patterns and trends in Netflix's content catalog through data cleaning, exploratory data analysis (EDA), and data visualization.

The analysis explores the distribution of movies and TV shows, content ratings, release years, genres, countries, directors, and content durations.

## 🎯 Project Objectives

- Explore and understand the Netflix dataset.
- Clean and preprocess missing and inconsistent data.
- Analyze the distribution of movies and TV shows.
- Identify the most common content ratings and genres.
- Explore Netflix content additions over time.
- Identify the countries and directors with the highest number of titles.
- Analyze movie duration distributions.
- Visualize the main findings using statistical charts.

## 🛠️ Technologies & Libraries

- **Python** – Main programming language.
- **Pandas** – Data manipulation and analysis.
- **NumPy** – Numerical operations.
- **Matplotlib** – Data visualization.
- **Seaborn** – Statistical data visualization.
- **WordCloud** – Word cloud generation.

## 📊 Analysis Process

### 1. Data Importation and Exploration
- Import the Netflix dataset.
- Examine the dataset structure and dimensions.
- Explore column names, data types, and descriptive statistics.

### 2. Data Cleaning and Preprocessing
- Identify missing values.
- Handle missing information in columns such as director, cast, country, and rating.
- Convert date columns into datetime format.
- Extract year and month information from dates.

### 3. Content Distribution
- Compare the number of movies and TV shows.
- Explore the distribution of content ratings.
- Visualize the different content categories.

### 4. Time-Based Analysis
- Analyze the yearly distribution of content added to Netflix.
- Explore monthly content additions.
- Identify the years with the highest number of released titles.

### 5. Genre and Country Analysis
- Identify the top 10 most common genres.
- Explore the top 10 countries represented in the dataset.

### 6. Directors and Content Analysis
- Identify the 10 directors with the most titles.
- Generate a word cloud based on Netflix titles.
- Analyze the distribution of movie durations.

## 🚀 Getting Started

### Prerequisites

- Python 3.x
- Jupyter Notebook

### Installation

1. Clone the repository:

```bash
git clone https://github.com/Nevil-Nexus/netflix-data-analysis.git
```

2. Navigate to the project directory:

```bash
cd netflix-data-analysis
```

3. Install the required libraries:

```bash
pip install numpy pandas matplotlib seaborn wordcloud
```

4. Make sure the dataset is located inside the `Dataset` folder.

5. Open the notebook:

```bash
jupyter notebook Script.ipynb
```
